# Beitragen

Danke für das Interesse an chester. Beiträge sind willkommen, sobald der
Quellcode veröffentlicht ist.

## Contributor License Agreement

Vor dem ersten Merge unterschreibt jede beitragende Person oder Organisation
das Contributor License Agreement (CLA) der chester GmbH. Es räumt chester das
Recht ein, den Beitrag auch unter einer kommerziellen Lizenz anzubieten. Das
Urheberrecht am Beitrag bleibt bei der beitragenden Person.

Der Text steht in [CLA.md](CLA.md). Beim ersten Pull Request fragt der CLA Assistant die Zustimmung per Klick ab.

## Ablauf

1. Issue anlegen und das Vorhaben kurz beschreiben
2. Fork, Branch, Änderung mit Test
3. Pull Request gegen `main`
